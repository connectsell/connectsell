# 이메일 이미지 엑박 방지 가이드 (인플루언서·유튜버 제안용)

인플루언서/유튜버가 **일주일·한 달 뒤에 메일을 열어도** 이미지가 깨지지 않도록 정리한 문서입니다.

---

## 1. 적용 완료된 조치 (현재 상태)

- **모든 이메일 템플릿**의 이미지·링크를 **connectsell.co.kr** 로 통일했습니다.
  - `kakkukishake-email.html` (v1)
  - `kakkukishake-email-v2.html`, `kakkukishake-email-v3.html`, `kakkukishake-email-v3-latest.html`
  - `kakkukishake-email-v3-濡쒖뺄誘몃━蹂닿린.html` (모바일 버전)
  - `공동구매_제안서.html`, `kakkukishake.html`, `kakkukishake-email-v3-local.html`
- **이미지 URL**: `https://www.connectsell.co.kr/email/images/파일명.png`
- **샘플 신청 링크**: `https://www.connectsell.co.kr/sample/landing.html`
- Netlify 주소(sweet-paletas, stunning-syrniki 등)는 **더 이상 사용하지 않습니다.**

---

## 2. 앞으로 지켜야 할 것 (엑박 방지)

### ① 이메일에는 connectsell.co.kr 만 사용
- 새 템플릿을 만들거나 수정할 때 **이미지 주소·버튼 링크**는 반드시  
  `https://www.connectsell.co.kr/...` 로 넣어주세요.
- **Netlify 주소**(예: xxx.netlify.app)는 이메일용으로 쓰지 마세요.  
  (사이트가 일시 중지되면 며칠 뒤 메일을 열었을 때 엑박이 됩니다.)

### ② connectsell.co.kr 배포 시 email/images 유지
- connectsell.co.kr 에 배포할 때 **email/images/** 폴더가 빠지지 않도록 하세요.
- 배포 후 브라우저에서 아래 주소가 **이미지가 보이는지** 확인하세요.  
  `https://www.connectsell.co.kr/email/images/gakkuki-product.png`

### ③ connectsell.co.kr 이 Netlify인 경우
- connectsell.co.kr 이 Netlify에 연결되어 있다면,  
  **사이트가 사용 한도로 일시 중지(pause)되지 않도록**  
  Netlify 대시보드에서 사용량·플랜을 관리하세요.
- 이메일 이미지는 “언제 열어도” 같은 URL로 요청되므로,  
  **한 번이라도 사이트가 꺼지면** 과거에 보낸 메일까지 전부 엑박이 됩니다.

---

## 3. 새 이미지를 넣을 때

1. 파일을 `connectsell/email/images/` 폴더에 저장합니다.
2. HTML에서는 주소를 **항상**  
   `https://www.connectsell.co.kr/email/images/파일명.확장자`  
   로 작성합니다.
3. connectsell.co.kr 배포를 한 뒤,  
   `https://www.connectsell.co.kr/email/images/파일명.확장자` 가 브라우저에서 열리는지 확인한 다음 이메일을 발송합니다.

---

## 4. 요약

| 항목 | 권장 |
|------|------|
| 이메일 이미지 URL | `https://www.connectsell.co.kr/email/images/...` 만 사용 |
| 샘플/랜딩 링크 | `https://www.connectsell.co.kr/sample/landing.html` |
| Netlify 주소 | 이메일 템플릿·이미지에 사용 금지 |
| 배포 | email/images 포함해서 배포, 배포 후 URL 직접 열어서 확인 |

이렇게만 지키시면, **보낸 뒤 일주일·한 달이 지나서 열어도** 이미지가 엑박 없이 보이도록 유지할 수 있습니다.
