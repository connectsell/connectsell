■ 1. 이메일 HTML (kakkukishake-email.html)
-----------------------------------------
• 네이버/웹에서 비율 유지: 본문을 600px 고정으로 통일
  - 최상위 테이블·히어로·타이틀·카드·이미지 등 모두 width="600" / width:600px; max-width:100%;
  - 히어로 이미지: 600x180 고정 (가로 넓고 세로 짧은 비율)
  - Gmail 모바일은 앱 한계로 반응형 적용 어려움 → "웹에서 보기" 링크로 보완 권장

• 적용 규칙
  - 발송일시가 이미 있는 행은 스킵(재발송 방지)
  - 발송 성공: 발송일시 기록, 발송여부 공란
  - 발송 실패: 발송일시 기록, 발송여부 "오류"
  - 메일 본문 "000님" → 엑셀의 셀러명으로 치환

■ 2. 엑셀 기반 이메일 발송 스크립트
-----------------------------------------
• 생성한 파일
  - send_emails.py          : 엑셀 읽기 → 000→셀러명 치환 → 발송 → 발송일시/발송여부 기록 후 엑셀 저장
  - 이메일링_사용법.txt      : 사용 방법, Gmail/네이버 설정, 실행 예시 (한글)
  - requirements_email.txt  : pip install openpyxl
  - make_sample_excel.py    : 샘플 엑셀 생성용
  - 셀러_이메일목록_샘플.xlsx : NO, 셀러명, 이메일주소, 발송일시, 발송여부 형식 샘플
  - run_이메일링_260302.py   : Downloads의 "이메일링_260302.xlsx"로 실행하는 진입 스크립트

• 엑셀 컬럼
  A: NO, B: 셀러명, C: 이메일주소, D: 발송일시, E: 발송여부

• 실행 방법
  cd C:\Users\USER\connectsell\email
  python run_이메일링_260302.py
  (또는 python send_emails.py "엑셀파일경로")
  ※ 발송은 사용자 PC에서 사용자 메일 계정으로만 가능 (스크립트 실행 시 발송됨)

■ 3. 기타
-----------------------------------------
• 메일 보내는 방법 이미지 가이드 생성 (이미지 파일은 Cursor 프로젝트 assets 쪽에 생성됨)
• Gmail 모바일 반응형 ↔ 네이버 비율 충돌 정리: 한 쪽 수정 시 다른 쪽이 깨지는 한계 설명, 600px 고정 + 웹에서 보기 링크 권장
