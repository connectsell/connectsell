# 공동구매 제안서 수정 가이드

## 치환할 항목

| 항목 | 설명 | 예시 |
|------|------|------|
| `{인플루언서명}` | 수신자 이름 | 홍길동 |
| `[상품명]` | 제안 상품명 | 가꾸기 단백질 쉐이크 4종 |
| `[시작일] ~ [종료일]` | 공동구매 기간 | 2025.03.01 ~ 2025.03.15 |
| `[샘플 제공 / 수수료 등]` | 제안 조건 | 샘플 4종 무료 제공, 판매 수수료 15% |
| `[제품 설명...]` | 제품 소개 문구 | 274kcal, 4가지 맛... |
| 샘플 신청 링크 | 상품별 랜딩 URL (로컬) | file:///C:/Users/USER/connectsell/sample/landing.html |

## 사용 방법

1. `공동구매_제안서_템플릿.html` 열기
2. `[ ]` 안 내용을 실제 상품 정보로 수정
3. 이메일 발송 시 `{인플루언서명}`만 수신자별로 치환
