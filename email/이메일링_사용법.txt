========================================
엑셀 기반 이메일 발송 스크립트 사용법
========================================

[1] 엑셀 파일 형식
-----------------
반드시 아래 5개 컬럼이 있어야 합니다 (1행은 헤더).

  A열: NO
  B열: 셀러명      → 메일 본문 "000님" 자리에 들어갑니다.
  C열: 이메일주소  → 수신 주소
  D열: 발송일시    → 스크립트가 발송 후 자동 기록 (비워 두세요)
  E열: 발송여부    → 스크립트가 자동 기록. 성공=공란, 실패=오류

발송일시가 이미 채워진 행은 "이미 발송함"으로 건너뜁니다.
새로 보낼 사람만 발송일시/발송여부를 비워 두고 실행하세요.


[2] Python 설치
-----------------
Python 3.7 이상이 필요합니다.
설치 확인: 명령 프롬프트에서  python --version

필요 패키지 설치 (한 번만):
  pip install openpyxl


[3] 발신 메일 설정 (Gmail 예시)
-----------------
스크립트를 열어 상단의 다음 두 줄을 수정하거나,
시스템 환경 변수로 EMAIL_SENDER, EMAIL_APP_PASSWORD 를 넣어도 됩니다.

  EMAIL_SENDER = "본인@gmail.com"
  EMAIL_APP_PASSWORD = "Gmail 앱 비밀번호 16자리"

※ Gmail 앱 비밀번호: Google 계정 → 보안 → 2단계 인증 켜기 → 앱 비밀번호 생성

네이버 메일로 보내려면:
  스크립트 상단에서
  SMTP_HOST = "smtp.naver.com"
  SMTP_PORT = 587
  으로 바꾸고, EMAIL_SENDER는 네이버 주소, EMAIL_APP_PASSWORD는 네이버 메일 비밀번호로 설정.


[4] 실행 방법
-----------------
명령 프롬프트(또는 터미널)에서:

  cd C:\Users\USER\connectsell\email
  python send_emails.py "엑셀파일전체경로"

예 (Downloads의 이메일링_260302.xlsx 사용 시):
  python run_이메일링_260302.py
  또는
  python send_emails.py "C:\Users\USER\Downloads\이메일링_260302.xlsx"

다른 엑셀 파일 사용 예:
  python send_emails.py "C:\Users\USER\Desktop\셀러_이메일목록.xlsx"

실행 후:
- 발송 성공한 행: 발송일시에 날짜/시간, 발송여부는 공란
- 발송 실패한 행: 발송일시에 날짜/시간, 발송여부에 "오류"
- 같은 엑셀 파일이 그대로 덮어써지므로, 발송 결과가 담긴 엑셀을 그대로 보관하시면 됩니다.
