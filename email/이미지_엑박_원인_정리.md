# 이메일 이미지 며칠 후 엑박 원인

## 확인된 사유: **호스팅 중지 (Netlify 사이트 일시 중지)**

### 무슨 일이 있었나

| 시점 | 상황 |
|------|------|
| **메일 보낼 때** | 이미지 주소가 `https://sweet-paletas-75c804.netlify.app/email/images/...` 인 템플릿으로 발송. 당시 Netlify 사이트가 켜져 있어서 이미지가 정상 표시됨. |
| **며칠 후** | Netlify에서 해당 사이트가 **사용 한도 초과로 일시 중지(pause)** 됨. 같은 이미지 주소로 요청해도 "Site not available"만 반환. |
| **결과** | 메일을 다시 열면 이미지를 불러오지 못해 **엑박**으로 보임. |

### 근거

- 지금 `https://sweet-paletas-75c804.netlify.app/email/images/gakkuki-product.png` 접속 시  
  → **"This site was paused as it reached its usage limits"** 메시지가 뜸 (사이트 중지 상태).
- **v1 이메일** (`kakkukishake-email.html`) 은 모든 이미지를 이 Netlify 주소로 쓰고 있음.
- **connectsell.co.kr** 주소(`https://www.connectsell.co.kr/email/images/...`) 는 현재 정상 응답(200).

### 결론

- **가능한 원인 중 실제 원인:**  
  **Netlify 사이트가 사용 한도로 일시 중지되면서, 그 주소로 연결된 이미지가 며칠 후부터 엑박으로 보이게 된 것.**

---

## 다른 원인은?

| 원인 | 해당 여부 |
|------|-----------|
| **호스팅 중지** | ✅ **해당** – sweet-paletas Netlify 사이트가 pause 됨. |
| **재배포 시 경로 누락** | ❌ connectsell.co.kr 은 `/email/images/` 정상 응답. |
| **임시 URL** | ❌ 사용 중인 URL에 만료 파라미터 없음. |

---

## 앞으로 조치

1. **이미지 주소를 connectsell.co.kr 로 통일**  
   - v1 등 Netlify URL 쓰는 템플릿을 `https://www.connectsell.co.kr/email/images/...` 로 바꾸면, Netlify가 꺼져 있어도 엑박이 나지 않음.
2. **Netlify 사용 시**  
   - 사이트가 pause 되지 않도록 사용량/플랜을 확인하거나,  
   - 이메일용 이미지는 connectsell.co.kr 처럼 **중지되지 않는 호스팅**에 두는 것을 권장.
