# ConnectSell

웰니스 공동구매 중계 플랫폼 공식 웹사이트

## 배포

- **GitHub Pages**: 저장소 설정 → Pages → Source: main 브랜치 → Save
- **Netlify / Vercel**: GitHub 저장소 연결 후 자동 배포

## 구조

```
connectsell/
├── index.html
├── styles.css
├── script.js
├── images/
│   ├── rolling/     # 브랜드 롤링 이미지
│   ├── influencer/   # 인플루언서 카드 이미지
│   ├── partners/    # 파트너 아바타
│   └── ...
└── video/           # 메인/명함 영상
```
